TeamKangnam — 행동 트리(BT) 에이전트 실행 방법
=================================================

제출물 구성
-----------
- AIP_DCS_TeamKangnam.dll   : 컴파일된 BT 두뇌 (원본 파일명 AIP_DCS_team01.dll, 제출용으로 개명)
- Rule_TeamKangnam.xml      : 그 두뇌가 참조하는 전술 트리 정의 (원본 파일명 Rule_v1.xml, EmergencyPullUp
                              1500m 등 8/22 최종 튜닝값 반영판). DLL과 반드시 세트로 사용.
- source_AIP_DCS/           : 위 DLL을 만든 C++ 소스 전체 (Visual Studio 프로젝트, git HEAD 기준)
                              GitHub: https://github.com/kevin53202-crypto/AIP_DCS-v1-backup (private)
                              커밋: f060339 ("v1: revert filtered-UTAngle isolation test, back to 21ceb9b baseline")

주의(중요): 프로젝트 폴더에 `AIP_DCS_TeamKangnam.dll`이라는 이름의 파일이 하나 더 있는데, 그건
팀원이 비교용으로 공유한 별도 BT(소스 없음, 스파링 상대용)이니 혼동 금지. 이 제출물에 들어있는
건 본인 GitHub 리포(AIP_DCS, team01) 빌드임.

1. 실행 (권장 — 기존 대회 제공 환경 사용)
------------------------------------------
DLL·XML 파일명은 바꾸지 말고, 대회 측 DogFightEnv/Release/ 폴더에 두 파일을 복사한 뒤
아래 명령으로 실행합니다.

    python run_unreal_inference.py --mode bt ^
        --bt-dll AIP_DCS_TeamKangnam.dll ^
        --bt-rule-xml Rule_TeamKangnam.xml ^
        --team-name TeamKangnam ^
        --server-ip <서버 IP> ^
        --server-port 9999

(참고: DLL이 실행 시 XML을 Rule_forTraining.xml이라는 고정 이름으로 복사해서 읽으므로,
run_unreal_inference.py가 자동으로 이 복사를 처리합니다. 수동으로 파일명을 바꿀 필요 없음.)

2. 소스에서 직접 빌드하려는 경우
----------------------------------
source_AIP_DCS/AIP_DCS.sln 을 Visual Studio(v143 도구 집합, C++ 데스크톱 개발 워크로드)로 열고
Release | x64 구성으로 빌드하면 AIP_DCS.dll이 생성됩니다. 이 파일을
AIP_DCS_TeamKangnam.dll로 이름만 바꿔서 사용하면 동일한 결과가 나옵니다.

주의: 동봉한 AIP_DCS_TeamKangnam.dll은 이미 팀 내부 라이브 테스트로 검증된 바이너리이며,
소스에서 새로 빌드한 결과와 완전히 바이트 단위로 동일함을 별도 확인하지는 않았습니다.
가능하면 동봉된 DLL을 그대로 사용하는 것을 권장합니다.
